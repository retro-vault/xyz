# iec60559_fromfp

The fromfp and ufromfp functions are available when IEC 60559 binary floating-point is claimed.

- Category: `iec-60559`
- Support level: `conditional`
- Primary test file: `run.c`
- Test kind: `run`
- Allowed stdout: `'OK iec60559_fromfp', 'NOT-CLAIMED iec60559_fromfp'`
